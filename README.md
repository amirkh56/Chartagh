# چارطاق

سایت آژانس خلاق **چارطاق**؛ طراحی سایت، طراحی پوستر، طراحی سه‌بعدی و سئو، با پنج سال تجربه.
طراحی سایت از معماری و هنر ایرانی، به‌خصوص دوره‌ی صفوی، الهام گرفته: کاشی‌کاری، میناکاری، چهل‌تیکه و طاق‌های جناغی.

ساخته‌شده با **Next.js 16**، **React 19**، **Three.js** (React Three Fiber)، **Framer Motion** و **Lenis**.

---

## نصب و اجرا

### پیش‌نیازها

- **Node.js نسخه‌ی ۲۰.۹ یا بالاتر** (با `node -v` چک کن)
- npm (همراه Node نصب می‌شه)

### قدم‌به‌قدم

</div>

```bash
git clone https://github.com/amirkh56/Chartagh.git
cd Chartagh
npm install
npm run dev
```

<div dir="rtl">

بعد مرورگر رو روی [http://localhost:3000](http://localhost:3000) باز کن.

### دستورها

| دستور | کارش |
|---|---|
| `npm run dev` | اجرای حالت توسعه با بارگذاری خودکار تغییرات |
| `npm run build` | ساخت نسخه‌ی نهایی (پروداکشن) |
| `npm run start` | اجرای نسخه‌ی ساخته‌شده؛ اول باید `build` زده باشی |

### اگه `npm install` خطای شبکه داد

اگه به `registry.npmjs.org` دسترسی کند یا قطع‌ووصل داری (خطای `ECONNRESET` یا timeout)، از یه میرور استفاده کن:

</div>

```bash
npm install --registry=https://mirror-npm.runflare.com
```

### انتشار

سایت کاملاً استاتیکه و همه‌ی صفحه‌هاش موقع بیلد ساخته می‌شن. روی هر سرویسی که Next.js رو پشتیبانی می‌کنه (Vercel، لیارا، ران‌فلر و…) یا هر سرور Node با `npm run build && npm run start` بالا میاد.

## دیزاین سایت

### ایده

اسم «چارطاق» از بناهای ساسانی می‌آد: چهار ستون و یه گنبد. ما همین رو استعاره‌ی چهار خدمت آژانس گرفتیم: **«چهار ستون محکم برای برند تو»**. هر جای سایت که بشه، این چهار تا کنار هم میان: چهار برچسب دور چارطاق سه‌بعدی، چهار تیکه‌ی چهل‌تیکه، چهار مرحله‌ی کار.

### لحن

رفاقتی و خودمونی، بدون تعارف: «سلام رفیق!»، «بزن بریم»، «یه چای مهمون ما؟». متن‌ها کوتاهن و گرم.

### پالت رنگ

برگرفته از رنگ آجر، کاه‌گل و کاشی:

| نام | کد | کاربرد |
|---|---|---|
| آجری روشن | `#E2492D` | رنگ اصلی برند، دکمه‌ها، تأکیدها |
| آجری میانه | `#B5391F` | متن‌های تأکیدی (کنتراست بهتر روی زمینه‌ی روشن) |
| آجری تیره | `#7E2414` | لودر، بخش دعوت، منوی موبایل |
| کاه‌گل | `#F8DDD3` | سطح‌های روشن، متن روی زمینه‌ی تیره |
| دوده | `#24130E` | متن اصلی، فوتر |
| فیروزه | `#22B8B0` | رنگ مکمل، هایلایت‌ها، نور تم شب |
| لاجورد | `#2C4FA0` | رنگ مکمل، کاشی‌ها و الگوها |
| ماسه | `#D9C5A0` | جزئیات |

همه‌ی رنگ‌ها به‌صورت متغیر CSS بالای `app/globals.css` تعریف شدن.

### تم روز و شب

- **روز (پیش‌فرض):** زمینه‌ی کرم گرم `#F7EEE5`، متن دوده‌ای، الگوها آجری کم‌رنگ.
- **شب:** زمینه‌ی قهوه‌ای خیلی تیره `#140A07`، متن کاه‌گلی، الگوها و نور موس فیروزه‌ای؛ زیر چارطاق سه‌بعدی یه فانوس روشن می‌شه.
- تغییر تم با یه دایره‌ی بازشونده از روی دکمه انجام می‌شه (View Transitions API). انتخاب کاربر ذخیره می‌شه و قبل از نمایش صفحه اعمال می‌شه تا صفحه چشمک نزنه.

### تایپوگرافی

- فونت **دانا** با اعداد فارسی در وزن‌های ۳۰۰ تا ۹۰۰
- تیترها: وزن ۹۰۰، اندازه‌ی سیال با `clamp()`
- فاصله‌ی خطوط برای فارسی بیشتر گرفته شده (متن ۱.۹، تیترها حدود ۱.۲۵)
- فاصله‌ی حروف (letter-spacing) دست نخورده، چون حروف فارسی به هم چسبیده‌ان
- انیمیشن‌های متن فقط **کلمه‌به‌کلمه**ن، هیچ‌وقت حرف‌به‌حرف، تا اتصال حروف نشکنه

### نقش‌مایه‌های ایرانی

همه‌ی نقش‌ها با ریاضی در `lib/patterns.js` تولید می‌شن. به‌صورت ماسک CSS استفاده می‌شن، پس با تغییر تم رنگشون هم عوض می‌شه:

| نقش | کجا |
|---|---|
| **خاتم** (ستاره‌ی هشت‌پر) | هیرو، لودر، منو |
| **گره** (هشت‌ضلعی و ستاره) | ایوان هیرو، پرده‌ی جابه‌جایی، بخش دعوت |
| **طاق‌نما** (ردیف طاق جناغی) | کارت پوستر، کارت تماس |
| **لوزی** | کارت سئو |
| **گل‌چندپر** (میناکاری) | آمار |
| **شمسه** (ترنج خورشیدی صفوی) | بخش «ما کی هستیم؟»، سربرگ صفحه‌ها، پیش‌نمایش سایت |
| **حاشیه‌ی کاشی** | بالای فوتر |

**طاق جناغی** (قوس تیزه‌دار ایرانی) به‌عنوان ماسک روی کارت‌های فرایند، قاب نمونه‌کارها و تصویر پیش‌نمایش سایت استفاده شده.

### لوگو

نسخه‌ی وکتور ایزومتریک: مکعبی که دو وجهش با طاق جناغی بریده شده و روی بامش عدد «۴» پیکسلی نشسته. رنگ وجه‌ها با متغیرهای `--logo-*` کنترل می‌شه.

### سه‌بعدی (Three.js)

- **چارطاق هیرو:** چهار دیوار آجری با بافت آجر که با کد ساخته شده، بام با «۴» برجسته (تاج)، گنبد پیازی، ستاره‌های هشت‌پر و کاشی‌های براق شناور، و حلقه‌ای از کاشی‌های ریز که دورش می‌چرخن.
  - با حرکت موس می‌چرخه و یه نور هم دنبال موس می‌آد.
  - اگه بکشیش می‌چرخه؛ اگه کلیک کنی می‌پره و کاشی‌ها می‌تپن.
- **شمسه‌ی سه‌بعدی** در بخش دعوت: حلقه‌های کاشی که خلاف هم می‌چرخن. با هاور تند می‌شن و با کلیک باز و جمع می‌شن.
- صحنه‌ها فقط وقتی دیده می‌شن رندر می‌شن، تا روی گوشی باتری و پردازنده هدر نره.

### تعامل و انیمیشن

- **لودینگ:** لوگو تیکه‌تیکه سر هم می‌شه، درصد با اعداد فارسی بالا می‌ره، بعد دو لنگه در با نقش خاتم باز می‌شن.
- **جابه‌جایی بین صفحه‌ها:** پرده‌ای با لبه‌ی طاقی و لوگوی چارطاق صفحه رو می‌پوشونه و دوباره کنار می‌ره.
- **کرسر:** ستاره‌ی هشت‌پر چرخان. روی لینک‌ها بزرگ می‌شه و روی بخش‌های خاص برچسب نشون می‌ده («بکش و بچرخون»، «ببین»، «به‌زودی»).
- **کلیک روی جای خالی:** انفجار کاشی‌های رنگی با یه موج ستاره‌ای. حرکت سریع موس هم ردی از کاشی‌های ریز جا می‌ذاره.
- **نور موس:** الگوی پس‌زمینه‌ی هیرو، کارت‌ها، بخش دعوت و اسم بزرگ فوتر زیر موس روشن می‌شن.
- **کارت‌ها:** با موس کج می‌شن، یه درخشش روشون می‌افته و لایه‌های تصویرشون جابه‌جا می‌شن.
- **دکمه‌ها:** با نزدیک شدن موس به سمتش کشیده می‌شن و رنگ از پایین روشون پر می‌شه.
- **اسکرول نرم** با Lenis و انیمیشن‌های وابسته به اسکرول.
- **نوارهای متحرک** که سرعت و جهتشون از سرعت اسکرول تبعیت می‌کنه.

### بخش‌های صفحه‌ی اصلی

1. **هیرو:** «چهار ستون محکم برای برندِ تو» + چارطاق سه‌بعدی در قاب ایوان
2. **نوارهای متحرک:** خدمات و شعارها
3. **ما کی هستیم؟:** متنی که با اسکرول کلمه‌به‌کلمه روشن می‌شه
4. **خدمات:** چهار تیکه‌ی رنگی کنار هم به سبک چهل‌تیکه، با درز دوخت
5. **هنر طراحی سایت:** با اسکرول، یه سایت جلوی چشم کاربر ساخته می‌شه: اسکچ، طراحی، انیمیشن، کدنویسی، و آخر لانچ و سئو
6. **آمار:** ۵ سال تجربه، ۴ تخصص، ۱ تیم، ∞ استکان چای
7. **فرایند:** چهار کارت طاق‌شکل؛ گپ و چای، نقشه‌کشی، بنّایی، افتتاحیه
8. **نمونه‌کارها:** قاب‌های طاقی خالی با برچسب «به‌زودی»
9. **سؤال‌های رایج**
10. **دعوت:** «یه چای مهمون ما؟» + شمسه‌ی سه‌بعدی

### ریسپانسیو و دسترسی‌پذیری

- از ۳۲۰ پیکسل تا دسکتاپ بزرگ؛ نقطه‌های شکست در ۱۱۰۰، ۹۶۰ و ۶۴۰ پیکسل.
- روی گوشی، صحنه‌ی سه‌بعدی بالای متن هیرو می‌آد و منو تمام‌صفحه می‌شه.
- کرسر سفارشی فقط روی دستگاه‌های دارای موس فعاله.
- اگه کاربر «کاهش حرکت» رو فعال کرده باشه، انیمیشن‌ها و اسکرول نرم خاموش می‌شن.
- لینک «پرش به محتوا»، `lang="fa"` و `dir="rtl"`، برچسب‌های aria و فوکوس قابل‌دیدن هم رعایت شده.
